# ScummVM-S2 2026.4.0-s2.2

This is the first source-only preview of the unofficial ScummVM-S2 port.
It is based on ScummVM v2026.4.0 and contains the libounce path selection for
building a Nintendo Switch 2 NRO. The source is distributed under the GPLv3
terms in `COPYING`; upstream and third-party notices remain in the source tree.

No NRO or ZIP is attached to this release. Local builds exist, but their
statically linked dependency notices and matching build inputs have not yet
been fully audited for binary distribution. The port has not been tested on
Switch 2 hardware and remains an unverified build candidate.

Build instructions and current limitations are in `README.md`. No game data,
save files, keys, or other private material are included.
